# The Selection Icon is an opt-in permission, not an install-time one

Showing the Selection Icon on every page needs a content script on all sites, which makes the browser warn "Read and change all your data on all websites" at install. For an extension whose whole pitch is privacy, that warning is a bad first impression. So Glossa installs without any all-sites access: the context menu and the keyboard shortcut grant `activeTab`, and the content script is injected on demand. The Selection Icon is offered during onboarding and in Settings, and turning it on requests the all-sites host permission through `optional_host_permissions`. This choice is hard to reverse: moving the all-sites permission into the required set later would disable Glossa on update until each user re-approves it.
